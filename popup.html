使用说明

先用「完整编辑」保存主要资料；信息不足时，再用「新增 / 补充用户信息」补充。

使用步骤
  1. 点「完整编辑」填写并保存主要资料；额外信息通过「新增信息」补充。
  2. 打开任意企业官网的投递/网申页面。
  3. 在本扩展的 DeepSeek 设置中保存你的 API Key。
  4. 点击「一键填写本页」，由 DeepSeek 判断并填写。
  5. 默认保护已有内容，再次点击只补空白；也可使用网页右下角的悬浮入口。
💡 验证码、简历上传、同意条款等需按页面手动处理。
