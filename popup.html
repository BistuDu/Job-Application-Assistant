使用说明
使用步骤
  1. 点上方「➕ 新增信息」直接保存资料，复杂经历可在「完整编辑」中填写。
  2. 打开任意企业官网的投递/网申页面。
  3. 在本扩展的 DeepSeek 设置中保存你的 API Key。
  4. 选择模式1先规则填写再模型补充，或模式2直接用模型判断。
  5. 默认保护已有内容，再次点击只补空白；也可使用网页右下角的悬浮入口。
💡 验证码、简历上传、同意条款等需按页面手动处理。

🔒 画像和 Key 保存在本机。使用模型时，字段描述、同区域已有内容和画像内容会发送至 DeepSeek；验证码、上传和同意条款仍需手动处理。
