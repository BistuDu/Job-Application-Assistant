使用说明

先用「✏️ 编辑资料」用文字写清你的信息；随时可用「➕ 快速补充」追加新内容。

使用步骤
  1. 点「编辑资料」，用自然语言描述姓名、电话、教育、经历、家庭等真实信息，写明属于谁、哪段经历。
  2. 打开任意企业官网的投递/网申页面。
  3. 在本扩展的 DeepSeek 设置中保存你的 API Key。
  4. 点击「一键填写本页」，由 DeepSeek 判断并填写；结果里会逐条说明未填上的原因，可据此补充资料后重试。
  5. 默认保护已有内容，再次点击只补空白；也可使用网页右下角的悬浮入口。
💡 验证码、简历上传、同意条款等需按页面手动处理。

🔒 资料和 Key 保存在本机。使用模型时，字段描述、同区域已有内容及你的资料文本会发送至 DeepSeek；验证码、上传和同意条款仍需手动处理。
